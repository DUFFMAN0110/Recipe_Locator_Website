# Recipe Locator

## Description

Recipe Locator is a simple and accessible web application designed to help users quickly find recipes based on recipe names or ingredients.

Users can enter a recipe name or ingredient into the search bar and submit their search. The application asynchronously communicates with the Recipe API and displays matching recipe results. Users can then select a recipe to view additional information, including its description, category, cuisine, ingredients, and cooking instructions.

The primary goal of Recipe Locator is to provide an easy-to-use recipe search experience. The project intentionally focuses on searching for and viewing recipes rather than providing account management, user tracking, personalized meal planning, or other user-specific features.

### Main Features

- Search for recipes by recipe name or ingredient.
- Display multiple matching recipe results.
- View recipe descriptions.
- Select an individual recipe to view additional details.
- Expand and collapse ingredient information.
- Expand and collapse cooking instructions.
- Responsive design for desktop, tablet, and mobile screens.
- Accessibility-focused HTML structure, labels, focus indicators and live status messages.

## How to Run

Recipe Locator is currently designed to run locally; however, go to 'https://recipeapi.io/' to create an api key to then input into the 'const API_KEY="" ' for proper functionality. 

### Requirements

You will need:

- A modern web browser such as Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari.
- A valid Recipe API key.
- The Recipe Locator project files.
